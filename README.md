# AI_Quiz_Generator
AI Quiz Generator is a simple Python-based application that asks quiz questions, accepts user answers, validates responses, calculates scores, and displays final results automatically. The project works in the terminal/command prompt and demonstrates Python concepts such as loops, conditions, file handling, and user interaction.
## Description
A simple Python quiz application that asks questions, validates answers, calculates scores, and stores results.

## Features
- Welcome Message
- Quiz Questions
- Answer Validation
- Score Calculation
- Save Scores in Text File

## Technologies Used
- Python

## Run the Project
python quiz.py
